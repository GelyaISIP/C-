Автоматизированная система логистики заказов
=======
«Система логистики заказов» – WPF-приложение для автоматизации управления заказами, отгрузками, товарами и складами. Реализована ролевая модель: менеджер, кладовщик, клиент. Приложение использует Entity Framework 6 (Code First) и локальную базу данных SQL Server LocalDB.

Основные возможности:
-----------------------------------
### Авторизация и роли
* Вход по логину/паролю (пароль хешируется SHA256)
* При первой регистрации пользователь становится менеджером автоматически
* Последующие регистрации – клиенты
* Менеджер может менять роли другим пользователям (кроме первого менеджера и себя), тем самым назначать других пользователей кладовщиками или менеджерами

### Менеджер
Функции:
* Управление товарами (CRUD) + распределение остатков по складам
* Управление складами (CRUD)
* Управление заказами (просмотр, фильтр, изменение статуса, удаление)
* Управление отгрузками (создание, редактирование, удаление, подтверждение)
* Оформление заказа (в качестве служебного клиента)
* Отчёты (отгрузки, заказы, пользователи, просроченные отгрузки)
* Управление пользователями (смена ролей)
* Личный кабинет (смена пароля)

### Кладовщик
Функции:
* Просмотр и управление отгрузками (фильтры по складу, клиенту, статусу, датам)
* Создание отгрузок с выбором заказа и склада (проверка остатков)
* Подтверждение отгрузки (заполняется фактическая дата, заказ получает статус «Отгружен»)

### Клиент
* Оформление заказов (выбор товаров, количества, склада)
* История своих заказов
* Личный кабинет (смена пароля)

### Отчёты
Менеджер может формировать отчёты:
* По отгрузкам (количество по складам за период)
* По заказам (группировка по заказчикам)
* По пользователям (количество по ролям)
* Просроченные отгрузки – если фактическая дата больше плановой, либо заказ не завершён, а плановая дата прошла

### Технологии
Использовалось следующее:
* .NET Framework 4.7.2
* WPF (Windows Presentation Foundation)
* Entity Framework 6 (Code First)
* SQL Server LocalDB
* XAML, C# 7.3

Структура проекта:
-----------------------------------
LogisticSystem/
├── Helper/            – вспомогательные классы (конвертеры статусов)

├── Models/            – сущности (Client, Order, Product, Warehouse, Shipment, Stock, User)

├── Data/              – контекст базы данных (LogisticsContext)

├── Migrations/        – миграции EF (схема БД + Seed-метод)

├── View/              – все окна приложения (AuthorizeWindow, OrderWindow, ShipmentsWindow и др.)

├── App.config         – строка подключения к БД

├── App.xaml           – ресурсы приложения, StartupUri

└── LogisticSystem.csproj

Установка и запуск:
-----------------------------------
### Требования
* Windows 7/8/10/11
* Visual Studio 2019/2022 (с установленными компонентами: **.NET Framework 4.7.2 SDK, WPF, SQL Server LocalDB, EntityFramework**)

### Шаги
1. Скачать репозиторий
2. Открыть решение **LogisticSystem.sln** в Visual Studio.
3. Восстановить NuGet-пакеты (правой кнопкой на решении → «Восстановить пакеты») ИЛИ скачать пакеты вручную (обычно будет достаточно установить EntityFramework)
4. Создать базу данных – открыть «Консоль диспетчера пакетов» по пути «Tools (Средства) → NuGet Package Manager (Диспетчер пакетов NuGet) → Package Manager Console (Консоль диспетчера пакетов)» и выполнить: ```Update-Database```
5. БД создастся локально в экземпляре (LocalDB)\MSSQLLocalDB. Посмотреть можно в «Обозреватель объектов SQL Server», найти окно можно во вкладке Вид.
6. Запускаете приложение

### Начальный вход
* Первый зарегистрированный пользователь становится менеджером.
* Для теста можно зарегистрировать admin / любой пароль (минимум 6 символов).
* Далее войти под этим менеджером и добавить склады, товары, распределить остатки через панель управления.
* Зарегистрировать несколько пользователей
* Зайти за менеджера и раздать роли
* За клиентов создать заказы
* За кладовщика создать и подтвердить отгрузки
* За менеджера составить отчёты, просмотреть заказы и отгрузки
